# Kumo for SolidJS

A SolidJS port of Cloudflare Kumo. All 44 component families tracked in
`migration-status.json` have verified parity with the pinned React source. The
package remains private pending a separate release and versioning decision.

```tsx
import { Badge, Text } from "@photon-ai/kumo-solid";
import "@photon-ai/kumo-solid/styles";
```
