## Status

The SolidJS package does not yet publish a command-line executable.

<Callout type="warning">
  The existing `npx @cloudflare/kumo` CLI belongs to the React package and
  emits React block source. Do not use it to install blocks into a SolidJS
  application.
</Callout>

## Current Workflow

Use package imports for versioned components:

```tsx
import { Button, Dialog, Input } from "@photon-ai/kumo-solid";
```

Solid blocks are currently copied from
`packages/kumo-docs-astro/src/components/kumo/` into the consuming project.
The [component registry](/registry) remains available through this site's JSON
endpoint:

```bash
curl http://localhost:4321/api/component-registry
```
